# 唄まる -UtaMaru-

### Sorry, It's Japanese-Only for Now...
Support for additional languages is planned once the audio quality improvements have reached a satisfactory level.<br>
For now, development is focused on improving sound quality and stability.

**楽譜で指定した音程へ、Androidスマートフォンのマイク入力音声をリアルタイムで変換・出力。<br>
　普通に喋っているだけで歌っている様になるアプリです。
 
** 記録された楽譜を繰り返し再生しながら音階に合わせて声の音程を合わせ、スマホで再生したり<br>
　WindowsPC用USB/Wi-Fiマイクとしての利用も可能。<br>
　入力音声をそのまま送信・出力するモードも搭載しています。

- 対応OS：**Android 12以降（API 31以上）**<br>
- PCマイク機能：**Windows 10/11（64bit）**、USBまたはWi-Fi接続

現在、音質・安定性の改善を優先して開発中です。

## ダウンロード

公開済みのAPKやWindowsReceiverの配布ファイルは、このリポジトリの **Releases** から入手してください。<br>
Releasesに配布ファイルが表示されない場合は、まだ公開されていません。

- Android：`UtaMaru.apk` インストール用ファイル<br>
- Windows：`WindowsReceiver.zip` スマホをWindowsの仮想マイクとして使用する場合のみ。展開して使用します。

スマホ単体で使用する場合は**WindowsReceiver、ADB、VB-CABLEは必要ありません**。

## スマホだけで使用する場合

1. APKをAndroid 12以降の端末にインストールして起動し、マイクの使用を許可します。<br>
2. 楽譜を編集する場合は音階を文字列で入力するか、**「♫ 五線譜で楽譜を編集」** から音符やBPMを編集します。<br>
3. 音声変換エンジンを選びます。最初は **「標準」** での動作確認をおすすめします。<br>
4. **「マイク入力を音程変換して再生」** を押して開始します。変換せずに再生する場合は **「マイク入力をそのまま再生」** を押します。<br>
5. 停止するときは、使用中のボタンをもう一度押します。

※内蔵スピーカーを使う場合はハウリングに注意してください。

### 楽譜の入力形式（文字列で編集する場合）

- 音名 `C D E F G A B` と、任意の `#`（シャープ）、`b`（フラット）、オクターブ番号 `1`～`6` を並べます。例：`C4` `F#4` `Bb5`。<br>
- オクターブ番号を省略すると `4` になります（例：`C` は `C4`）。<br>
- **音符1個＝1拍**。音符同士の区切り文字は不要です。<br>
- **半角スペース1個＝休符1拍**。前後の空白も休符として扱われます。<br>
- 例：`D3A3F# GB3G3G`（`F#` と `G` の間に1拍の休符）。<br>
- 最大256拍。4拍子の小節が途中で終わる場合は、末尾が休符で補完されます。<br>
- BPMは五線譜編集画面で設定します（60～500、初期値200）。

楽譜は文字列を公開、コピー＆ペーストして他の利用者と共有できます。 

### 音声設定

- **標準**：通常の変換方式<br>
- **音質改善（PSOLA風）**：試験的な変換方式。周期的なノイズが出る場合があります<br>
- **Rubber Band**：Rubber Band Libraryを利用する方式（フォルマント維持）<br>
- **休符の音声出力**：生の声／無音／直前の音程を維持<br>
- **出力ブースト**：0～+18 dB。上げすぎるとノイズやハウリングが増幅されることがあります

変換倍率には設定された上限・下限があり、声の音程が楽譜の音に必ず完全一致するわけではありません。

## Windowsのマイクとして使う場合<br>

WindowsReceiverを使ってPCに音声を送り、VB-CABLE経由でDiscord・OBSなどの入力に利用できます。

詳しいセットアップ手順は **[WindowsReceiver/ReadMe.txt](WindowsReceiver/ReadMe.txt)** を参照してください。<br>
一応`START_PC_USB.bat`や`START_PC_WIFI.bat`を起動するだけで足りないファイルにチェックが入り<br>
足りなければそのDL先へ移動できる様にしてあります。

- USB接続：ADB（Google SDK Platform-Tools）が必要。アプリのPC接続先は `127.0.0.1`<br>
- Wi-Fi接続：PCとスマホを同じLANに接続し、アプリのPC接続先にPCのIPv4アドレスを入力<br>
- Windowsのマイク入力デバイスには **`CABLE Output`** を指定

VB-CABLEとADBは同梱していません。公式配布元から入手してください。

- [VB-CABLE（公式）](https://vb-audio.com/Cable/)<br>
- [Android SDK Platform-Tools（Google公式）](https://developer.android.com/tools/releases/platform-tools?hl=ja)

## 開発・ビルド

Android Studioでリポジトリのルートを開いてください。<br>
Android SDK API 36、JDK 17、対応するNDKとCMakeが必要です。<br>
SDKのパスは各自の `local.properties` に設定します（Git管理対象外）。

**Rubber Band Library 4.0.0のソースは `third_party/rubberband-4.0.0/` に同梱しています。<br>
** `SETUP_RUBBERBAND.bat` はソースが存在しない場合の再取得用で、通常のクローン後に毎回実行する必要はありません。<br>
Androidアプリのネイティブビルドには同梱ソースの `single/RubberBandSingle.cpp` を利用します。

`BUILD_UTAMARU_APK.bat` は **デバッグ署名のAPK** を作成します。Releasesに配布するAPKは、別途リリース署名してください。署名鍵とパスワードをGitHubにアップロードしないでください。

### 楽譜画像 to 唄まる用楽譜

以下の文章と共に楽譜の画像をAIへ渡すとAIが楽譜画像を唄まる用の楽譜(文字列)に変換してくれます。

添付した五線譜画像を、以下の独自形式の文字列楽譜に変換してください。<br>
【形式】<br>
音符は C4、F#4、Bb5 などで表記。対応音域はC1～B6。<br>
音符1個＝1拍。区切りなしで連結する。<br>
長い音は同じ音符を繰り返す。<br>
休符は半角スペース1個＝1拍。<br>
最大256拍、BPMは60～500。<br>
【変換ルール】<br>
原譜の音程・音の長さ・リズムをできるだけ正確に再現する。<br>
16分音符を1拍とする場合、8分音符＝2拍、4分音符＝4拍。BPMは原譜の4倍。<br>
256拍または500BPMを超える場合は、8分音符＝1拍、4分音符＝2拍に変更。BPMは原譜の2倍。<br>
16分音符や3連符が表現できない場合は、小節の長さを維持して近似する。<br>
できるだけ最初から最大256拍までを1本にまとめる。<br>
調号・臨時記号・付点・タイ・休符を正確に読み取る。<br>
【出力】<br>
推奨BPM<br>
コピー用の文字列楽譜（1行、不要なスペースなし）<br>
合計拍数と変換小節数<br>
近似・判読不明箇所<br>
各小節の音程と拍数を元画像と照合し、誤読や拍数のズレがないか確認してください。

### MIDI to 唄まる用楽譜

以下の文章と共にMIDIデータをAIに渡すとAIがMIDIデータを唄まる用の楽譜(文字列)に変換してくれます。

添付したMIDIファイル（または楽譜画像）を解析して、以下の仕様に従って音符をテキストへ変換してください。<br>
【変換ルール】<br>
ベースパートを除外し、それ以外のメロディー、対旋律、伴奏などの音符を抽出してください。<br>
複数の独立したパートがある場合は、混ぜずにパート別に出力してください。同じ音程・タイミングの重複トラックはまとめてください。<br>
各パートの音符を、演奏される順番に並べてください。<br>
音符は `C4` `D4` `F#4` のように表記してください。中央のドは `C4`（MIDIノート番号60）とします。<br>
半音は `#` を使用し、フラットは異名同音のシャープに統一してください。<br>
音符と音符の間にスペース、カンマ、改行、区切り文字を入れないでください。<br>
出力例：`C2D2E2G2C3D3E3G3C4`<br>
各音符は原則として1拍分として扱い、音符の長さは文字列に含めません。同じ音が連続する場合も省略しないでください。<br>
必要な1拍分の休符は半角スペース1つで表してください。ただし、原曲の細かなリズムを1拍単位に正確に変換できない場合は、無理に休符を補わず、音符の順序を優先してください。<br>
オクターブ変更などの移調は行わず、原曲の音程を維持してください。<br>
各パートについて、最初の150音を出力してください。<br>
画像の場合、読み取れない音符は推測で埋めず、その位置を報告してください。<br>
【出力形式】<br>
各パートの名前と音符数を示した後、変換した文字列をそれぞれコードブロックで出力してください。<br>
変換文字列には説明文を混ぜず、そのままコピーして使えるようにしてください。
