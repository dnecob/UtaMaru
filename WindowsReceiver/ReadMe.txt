★☆★ PCマイク機能の使い方 ☆★☆

PC用のマイクとして使用する場合は以下の作業が必要です。
スマホだけで使用する場合は必要ありません。
一応`START_PC_USB.bat`や`START_PC_WIFI.bat`を起動するだけで足りないファイルにチェックが入り
足りなければそのDL先へ移動できる様にしてあります。

## 1. 必要なもの ------------------------------------------------------------------------------

- Android 12以降のスマートフォン（唄まるをインストール済み）
- Windows 10 / 11（64bit）のPC
- WindowsReceiver（唄まるのPC用受信ソフト）
- VB-CABLE（仮想マイク用ソフト）
- USB接続の場合のみ、ADB（SDK Platform-Tools内）

**ダウンロード先**

- VB-CABLE（公式）：https://vb-audio.com/Cable/
- SDK Platform-Tools（Google公式）：https://developer.android.com/tools/releases/platform-tools?hl=ja

※ VB-CABLEとADBは利用者自身で公式サイトから入手してください。

※ Android Studioを導入済みで、SDK Platform-Toolsがインストールされている場合は、ADBの追加ダウンロードは不要です。

## 2. PCの初期設定（USB・Wi-Fi共通）--------------------------------------------------------------

1. VB-CABLEをインストールします。
2. 必要に応じてWindowsを再起動します。
3. サウンド設定を開き、入力が「CABLE Output」になっているのを確認します。
4. WindowsReceiverフォルダを好きな場所に展開します。
5. PCで音声を受信する準備ができたら、接続方法に応じたbatファイルを起動します。

WindowsReceiverを起動すると、VB-CABLEの「CABLE Input」へ受信音声が送られます。

## 3. USB接続で使う場合 --------------------------------------------------------------------------

・初回のみスマホ側のUSBデバッグ設定が必要です。

1. スマホの「設定」から「デバイス情報」などを開きます。
2. 「ビルド番号」を7回タップし、開発者向けオプションを有効にします。
3. 「開発者向けオプション」から「USBデバッグ」をONにします。
4. USBケーブルでスマホとPCを接続します。
5. スマホにUSBデバッグの許可画面が表示されたら、自分のPCであることを確認して許可します。

※ 設定項目の場所はスマホの機種によって異なります。

・PC側の操作

1. SDK Platform-Toolsをダウンロードし、適当な場所にZIPを展開します（Android StudioなどADB導入済みの場合は不要）。
2. WindowsReceiver内の `START_PC_USB.bat` を起動します。
3. 起動チェック時にファイル場所が要求されるので、1で展開した'adb.exe'や'AdbWinApi.dll'などが入っているフォルダを指定します。(Android Studioの場合は自動認識されます)
4. ADBが正しく認識され、スマホへの接続が成功するとWindowsReceiverが起動します。
5. 唄まるのPC接続先には `127.0.0.1` を指定します。
6. 「マイク入力を音程変換してPCへ送る」または「マイク入力をそのままPCへ送る」を押します。

※ USBデバッグは信頼できるPCでのみ許可してください。

## 4. Wi-Fi接続で使う場合 -------------------------------------------------------------------------

Wi-Fi接続ではADBもUSBデバッグも不要です。

1. スマホとPCを同じ家庭内LANなど、相互通信できるネットワークに接続します。
2. WindowsReceiver内の `START_PC_WIFI.bat` を起動します。
3. 表示されるPCのIPv4アドレスを確認します（例：192.168.1.10）。
4. 唄まるのPC接続先に、そのIPv4アドレスを入力します。
5. 「マイク入力を音程変換してPCへ送る」または「マイク入力をそのままPCへ送る」を押します。

Windowsファイアウォールの許可画面が出た場合は、信頼できるプライベートネットワークのみ許可してください。

※ 公共Wi-Fiやインターネットに受信ポートを公開しないでください。

## 5. 動作確認 -----------------------------------------------------------------------------------

アプリを介さず確認する場合の一時的なもの。

1. システムトレイの🔈️を右クリック、サウンドを選択します。
2. 「録音」タブを選択します。
3. 「CABLE Output」を選択してプロパティ(又は右クリックからプロパティ)をクリック。
4. 「聴く」タブを選択。
5. 「このデバイスを聴く」にチェックを入れます。
6. 上記「USB接続で使う場合」「Wi-Fi接続で使う場合」どちらかで音声が正常に入力・出力されているかを確認します。

※ 確認後、チェックを外しておくのを忘れずに。
※ ハウリングを防ぐ為、ヘッドホンを着用するかマイクとスピーカーの距離を離してください。

## 6. Windowsアプリのマイクとして使用する------------------------------------------------------------------

Discord・OBS・ゲームなどの音声設定を開き、マイク（入力デバイス）を次のように指定してください。

**マイク入力：CABLE Output（VB-Audio Virtual Cable）**

これで唄まるから送信した音声を、PCのマイクとして利用できます。

なお、VB-CABLEのデバイス名は紛らわしいので注意してください。

- CABLE Input：WindowsReceiverが音声を送り込む先
- CABLE Output：Discordなどで選択するマイク入力

## 7. うまく動かない場合--------------------------------------------------------------------------------

- **ADBが見つからない**：SDK Platform-Toolsが導入されているか確認してください。
- **USBでスマホを認識しない**：USBケーブル、USBデバッグ設定、スマホ側の許可画面を確認してください。
- **Wi-Fiで接続できない**：PCのIPv4アドレスとWindowsファイアウォール設定を確認してください。
- **PCで音が入らない**：VB-CABLEがインストールされているか、マイク入力が「CABLE Output」になっているか確認してください。
- **複数のAndroid端末を接続している**：ADBの接続先が競合する場合があるため、使用しない端末を外して再試行してください。

## 8. 使用終了 --------------------------------------------------------------------------------------

唄まるで送信中のボタンをもう一度押すと、音声送信が停止します。
WindowsReceiverも終了して構いません。
## 多言語対応について -------------------------------------------------------------

WindowsReceiverの起動案内は、Windowsの表示言語が日本語なら日本語、それ以外は英語になります。
コマンドプロンプトで set UTAMARU_LANG=en または set UTAMARU_LANG=ja とすると、
そのコマンドプロンプトから起動したBATの表示言語を手動指定できます。
受信EXE本体の診断ログは英語のままです。
